# copyseg
Copy functions for STS reduplication

Run from the command line as follows:

$ python3 copyseg.py string

this tests Copy-Seg as defined in McCarthy et al. (2012), formalized in Gouskova & Kasenov (2026)

to try asymmetric versions, run:

$ python3 copyseg.py string L

or 

$ python3 copyseg.py string R
